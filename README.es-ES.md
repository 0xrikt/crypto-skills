# 🎯 Crypto Skills

Una colección de AI Skills para el trading de criptomonedas.

## Skills

### 1. [Crypto Backtest](./crypto-backtest/)

**Valida tus ideas de trading en minutos**

Transforma ideas de trading en lenguaje natural en estrategias validadas con backtesting profesional, reportes detallados y código ejecutable.

- Lenguaje natural → Estrategia completa
- Backtesting con datos históricos reales
- Reportes HTML interactivos
- Salida de código Python ejecutable

```
"Compra BTC cuando RSI < 30, vende cuando RSI > 70"
→ Completado de estrategia completa → Backtest → Reporte → Código
```

### 2. [Crypto Trading Advisor](./crypto-trading-advisor/)

**Análisis profesional de trading de criptomonedas**

Una Claude Skill que ayuda a proporcionar análisis profesionales de trading de criptomonedas con fuentes de datos en tiempo real, principios de trading y marcos de gestión de riesgos.

```
"¿Es el BTC una buena operación en este momento?"
→ Análisis de datos → Niveles de Entrada/Salida → Evaluación de riesgo
```
